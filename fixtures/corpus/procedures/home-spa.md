# Home Spa

## Weekly maintenance

Use chlorine granules for the home spa. Check free chlorine before adding chemicals.

1. Remove the cover.
2. Test free chlorine and pH.
3. Add chlorine only when free chlorine is below the target range.
4. Run the jets for twenty minutes.

## Startup after drain

Fill the home spa, balance alkalinity, then add chlorine.
